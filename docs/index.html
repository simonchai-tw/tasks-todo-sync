現代人的工作與生活被不同平台切割。我們總是想用最順手的工具記下一筆待辦，但最終卻散落各處被遺忘。

兩階段確認刪除保護（Two-round Safeguard），避免因網路暫時斷線造成誤刪整個清單的悲劇。

自癒容錯 ⚙️
架構差異

為什麼你需要的是 專用狀態引擎，而非 Zapier 拼裝觸發器？

Zapier、Make 或 IFTTT 能靠「當這件事發生時就做那件事」串接 API，但維持兩套任務庫一致是嚴格的「分散式狀態問題」。

✕通用型自動化平台 (Zapier / Make)

  • 彼此孤立的單向觸發，極易互相打架或引發死循環
  • 修改一個字元可能被判定為新任務，不斷複製重複項目
  • 完成、重新開啟、移動分類與刪除邏輯必須手動拼湊
  • 所有私人任務資料皆需流經第三方商用主機
  • 隨任務量計費，常常超出免費用量產生每月份額帳單

✓Tasks–To Do Sync 專用同步引擎

  • 單一閉環狀態機：雙邊清單與任務維持持久穩定的 UUID 映射表
  • 完整生命週期：新增、編輯、完成、時區、移動、刪除統一生態處理
  • 專為雙平台量身打造：衝突比對、復原日誌、更名追蹤、墓碑紀錄
  • 100% 個人私有掌握：所有代碼、金鑰、狀態都在您自己的 Google 帳號
  • 完全免費與開源：MIT 授權，永久不收取任何訂閱月費

快速開始

兩種安裝路徑，今晚立即搞定同步

無論是習慣圖形介面的日常使用者，還是喜歡指令行的開發者，都能在 3 到 5 分鐘內快速完成個人部署。

1

取得專案腳本

在瀏覽器開啟 Google Apps Script，建立您的私有同步專案（或直接複製官方範本）。

2

部署私有網頁精靈

點擊「部署 → 新增部署作業 → 網頁應用程式」，設定僅限自己存取（私人安全）。

3

微軟 Device 登入

開啟私有 Setup 精靈，連線微軟官方 microsoft.com/link 輸入配對短碼，無須建立複雜 Azure App。

4

一鍵啟動自動排程

在精靈介面按下「Activate」，系統自動建立 10 分鐘同步觸發器，並完成首次健康檢查！

1

執行 init

在電腦終端機輸入指令，自動建立獨立 Apps Script 專案並推送最新發布版本代碼。

2

Google 授權確認

開啟終端機輸出的編輯器網址，執行一次初始化，確認個人 Google Tasks 權限。

3

Microsoft 授權

開啟部署的私有 Setup 網頁，在微軟官方網址輸入驗證碼完成綁定。

4

排程啟動

執行 createTrigger，每 10 分鐘自動背景同步，開始您的雙向任務流動。

terminal — 建立您的私有同步專案
$ npx tasks-todo-sync init

✨ 免終端機網頁安裝指引

1

建立 Google Apps Script 專案

前往 script.google.com 點選「新專案」，此專案完全屬於您的個人 Google 雲端，絕無任何外人可檢視代碼與資料。

2

匯入同步代碼或建立 Web App

複製 GitHub 最新發布版本程式碼，於編輯器右上角點選「部署」→「新增部署作業」，類型選擇「網頁應用程式 (Web App)」，存取權限設為「僅限自己」。

3

開啟私有安裝精靈 (Setup.html)

點開部署給您的專屬網址，跟隨網頁上的步驟：點選「Connect Microsoft」，在微軟官方網址輸入驗證碼完成授權（使用官方安全 Device Code Flow，免註冊複雜 Azure 憑證）。

4

點擊 Activate 啟動排程

完成兩端授權後，點擊網頁上的「Activate」按鈕，系統將自動啟動每 10 分鐘自動雙向同步排程，即刻生效！
